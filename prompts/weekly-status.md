# Weekly status (optional)

Schedule: Friday afternoon. Read-only.

---

Write {{owner.name}}'s weekly status summary for the week ending today (Monday through today). Reply in {{owner.language}}, concise, ready to paste as a status update. Read-only run: do not send messages, post anything, or change any files.

GATHER
1. List this week's conversations with the owner and, for the substantive ones, read what was done, decided, or left open.
2. Read the owner's notes that were updated this week for current status and decisions.
3. Check which scheduled tasks ran this week and their outcomes (mention only ones that matter, e.g. a failure to fix).
4. Attribution: only call something a decision if the owner stated or confirmed it; the agent's suggestions are not decisions. Don't invent progress; if a thread just stopped, list it as open.

WRITE (150–250 words)
Group by area where it helps. Three sections: Key accomplishments (one line each, concrete), Decisions, Still open (unresolved, waiting-on, next steps). Plain phrasing, no filler. Skip any section with nothing real in it. Leave out personal matters.

DELIVER
Send the summary titled "Week of <Mon date> – status".
